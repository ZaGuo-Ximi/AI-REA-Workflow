# 核心逆向分析 Prompt 模板

在使用 AI（如 Kilo Code 或 Claude Code）配合 REA 工具进行逆向分析时，大模型（尤其是上下文较小的免费模型）容易出现“偷懒”或“胡言乱语”的情况。
直接使用以下强指令模板，可以最大程度逼迫 AI 乖乖调用底层工具。

## 1. 基础 Jar 包/文件结构分析

> **提示词：**
> 请强制调用 rea 工具，分析一下 `[替换为你的文件绝对路径]` 这个文件。不要用普通的 Read 工具，请强制调用 `rea` 工具，帮我反编译并提取里面的主要类，告诉我这个包的核心功能是什么。

## 2. 防幻觉/防废话强指令（当 AI 发疯或拒绝调用工具时使用）

> **提示词：**
> 停止写任何代码。立刻使用 MCP 工具 `rea`。读取文件 `[替换为你的文件绝对路径]`。不要回答任何多余的话，不要用你自己的知识回答，只输出工具返回的原始结果。

## 3. 特定漏洞/逻辑排查

> **提示词：**
> 请调用 `rea` 工具分析 `[替换为你的文件绝对路径]`。重点搜索里面的 `[比如：exec, System, Runtime, 网络请求]` 相关的方法，并告诉我这些方法是否存在被利用的风险。

---
💡 **注意**：在执行上述指令前，请确保你的 AI 已经成功连接了 REA MCP 服务，并且模型具备一定的工具调用（Function Calling）能力。
